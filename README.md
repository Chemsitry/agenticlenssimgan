# Agentic COSMIC-Webb Sim

Multi-band JWST gravitational lens simulation pipeline using real COSMOS-Web survey data as backgrounds. Generates realistic synthetic strong lensing images for training ML classifiers.

## What it does

Simulates strong gravitational lensing events across 4 NIRCam bands (F115W, F150W, F277W, F444W) by:

1. **Extracting real backgrounds** from COSMOS-Web DR0.5 deep mosaics (~6184s exposure, 30mas pixel scale)
2. **Simulating lensing** with SIE + external shear models using COWLS-calibrated parameter distributions (Nightingale et al. 2025)
3. **Rendering multi-band images** with empirical PSFs, Poisson noise, Lyman-break aware source SEDs, and realistic lens/source galaxy profiles

Each output image is 125x125 pixels at 0.03"/pix across all bands.

## Pipeline versions

| Version | Script | Key features |
|---------|--------|-------------|
| v1 | `test_generate.ipynb` | Single-band F115W, Gaussian PSF, SIS lens |

## Setup

```bash
# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install numpy scipy astropy lenstronomy matplotlib
```

## Usage

### 1. Prep data (extract backgrounds + PSFs from COSMOS-Web mosaics)

Download the DR0.5 mosaics into `raw_data/1727_mosaic/`, then:

```bash
.venv/bin/python3 prep_mosaic.py
```

This produces `prepped_mosaic/` with 2000 background patches and empirical PSFs per band.

### 2. Run simulation

```bash
# Generate 10 test images
.venv/bin/python3 simulate_v3.py

# Generate full dataset
.venv/bin/python3 simulate_v3.py --n 2000
```

Output goes to `output/v3/` — per-band images, arc-only ground truth, labels, parameters, RGB previews, and metadata.
