Update 2026-06-09 — simulate_v3 has been superseded

This explainer still describes simulate_v3.py accurately, but the colleague's repo has since moved through v4 → v6 → v7 → v8 → v9_consistent (merged 2026-06-09). The biggest shift is in simulate_v8.py: instead of stitching a synthetic lens onto a separate background (the v3 approach explained below), each v8 sample is one real 630×630 JWST cutout with only the lensed arcs simulated on top. v9_consistent/ then ties the lens mass (σv) to the cutout's own photometry via a Faber–Jackson relation, fixing the v8 mass–light inconsistency.

Bugs fixed since this document was written (relevant when reading the v3 code below, and as known "tells" for the diagnostic GAN):

  • v6 augmentation: stamp rotation/flip was drawn per band, giving the same galaxy different orientations across the 4 bands (non-physical). Now decided once per system.
  • v8 source SED: star-forming color ratios were computed but never applied — arcs were colorless. Now arcs carry the Lyman-break/Balmer-break SED described in Section 5 of this page.
  • v8 scene pool: stars (diffraction spikes) leaked in as central "lens galaxies"; removed via a compactness cut.
  • v8 duplicates: non-lensed images could be pixel-identical; scenes are now sampled without replacement.

Output naming changed in v8+: sources_{band}.npy → arcs_{band}.npy (plus galaxies_{band}.npy for the untouched real scene). See gan_plan.md (“UPDATE 2026-06-09” section) for how this changes the GAN feedback plan.

 258def starforming_color_ratios(z_source, uv_slope=0.5):
 259    """NIRCam flux ratios for a star-forming galaxy at z_source.
 260
 261    v3: Lyman-break aware + UV slope diversity.
 262
 263    uv_slope controls the f_nu spectral index: ratio = (1.15/lambda)^uv_slope
 264      uv_slope > 0: blue (dust-free young starburst)
 265      uv_slope ~ 0: flat in f_nu
 266      uv_slope < 0: red (dusty star-forming, or older stellar population)
 267    """
 268    # Lyman break wavelength at this redshift (in microns)
 269    ly_break_um = 0.1216 * (1 + z_source)
 270
 271    # Band effective wavelengths (microns)
 272    band_waves = {'F115W': 1.15, 'F150W': 1.50, 'F277W': 2.77, 'F444W': 4.44}
 273
 274    ratios = {}
 275    for band, lam_eff in band_waves.items():
 276        if lam_eff < ly_break_um:
 277            # Below Lyman break — strong IGM absorption
 278            suppression = max(0.0, (lam_eff / ly_break_um) ** 3)
 279            ratio = suppression * 0.05
 280        else:
 281            # Above Lyman break — UV continuum with slope diversity
 282            ratio = (1.15 / lam_eff) ** uv_slope
 283        ratios[band] = max(ratio, 0.01)
 284
 285    # Normalize to F115W if it's above the break
 286    f115w_val = ratios['F115W']
 287    if f115w_val > 0.01:
 288        for band in ratios:
 289            ratios[band] /= f115w_val
 290    else:
 291        max_val = max(ratios.values())
 292        if max_val > 0.01:
 293            for band in ratios:
 294                ratios[band] /= max_val
 295
 296    return ratios

 301def add_poisson_noise(image_sim, band, rng=None):
 302    """Add Poisson shot noise to noiseless sim image."""
 303    if rng is None:
 304        rng = np.random.default_rng()
 305    s2e = BAND_CONFIG[band]['sim_to_elec']
 306    electrons = np.nan_to_num(image_sim * s2e, nan=0.0, posinf=0.0, neginf=0.0)
 307    electrons = np.clip(electrons, 0, None)
 308    # For very large lambda, use Gaussian approximation (Poisson→Normal)
 309    large = electrons > 1e8
 310    if large.any():
 311        noisy = np.empty_like(electrons)
 312        noisy[~large] = rng.poisson(electrons[~large]).astype(np.float64)
 313        noisy[large] = rng.normal(electrons[large], np.sqrt(electrons[large]))
 314        noisy = np.clip(noisy, 0, None)
 315    else:
 316        noisy = rng.poisson(electrons).astype(np.float64)
 317    return (noisy / s2e).astype(np.float32)

 322def stellar_mass(M, z):
 323    mM10=11.88; mu=0.019; mM00=0.0282; nu=-0.72
 324    gamma0=0.556; gamma1=-0.26; beta0=1.06; beta1=0.17

 327    gamma = gamma0*(z+1)**gamma1
 328    beta  = beta1*z + beta0

 409def simulate_one_multiband(lensed=True, seed=None):
 410    """Simulate one lens system in all 4 bands.
 411
 412    Returns dict with keys per band, each containing (image, image_source).
 413    Also returns shared params: theta_E, z_lens, z_source, mass, mStar.
 414    """
 415    rng = np.random.default_rng(seed)
 416
 417    # ── COWLS-calibrated redshifts ────────────────────────────────────
 418    z_lens = float(truncnorm.rvs(
 419        a=(ZLENS_LO - ZLENS_LOC) / ZLENS_SCALE,
 420        b=(ZLENS_HI - ZLENS_LOC) / ZLENS_SCALE,
 421        loc=ZLENS_LOC, scale=ZLENS_SCALE,
 422        random_state=int(rng.integers(int(1e9)))))
 423
 424    z_src_min = max(ZSRC_LO, z_lens + 0.1)
 425    for _ in range(100):
 426        z_source = float(truncnorm.rvs(
 427            a=(ZSRC_LO - ZSRC_LOC) / ZSRC_SCALE,
 428            b=(ZSRC_HI - ZSRC_LOC) / ZSRC_SCALE,
 429            loc=ZSRC_LOC, scale=ZSRC_SCALE,
 430            random_state=int(rng.integers(int(1e9)))))
 431        if z_source > z_lens + 0.1:
 432            break
 433    z_source = max(z_source, z_src_min)
 434
 435    # ── Velocity dispersion -> Einstein radius ───────────────────────
 436    sigma_v = float(truncnorm.rvs(
 437        a=(SIGMA_LO - SIGMA_LOC) / SIGMA_SCALE,
 438        b=(SIGMA_HI - SIGMA_LOC) / SIGMA_SCALE,
 439        loc=SIGMA_LOC, scale=SIGMA_SCALE,
 440        random_state=int(rng.integers(int(1e9)))))
 441
 442    lens_cosmo = LensCosmo(z_lens, z_source)
 443    theta_E = lens_cosmo.sis_sigma_v2theta_E(sigma_v) if lensed else 0.0
 444
 445    if lensed and not (THETA_E_LO <= theta_E <= THETA_E_HI):
 446        return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 447
 448    # ── Halo mass (galaxy-scale) ─────────────────────────────────────
 449    log_mass = float(rng.uniform(LOGMASS_LO, LOGMASS_HI))
 450    mass = 10**log_mass
 451    mStar = stellar_mass(mass, z_lens)
 452
 453    # ── Galaxy shape parameters (shared across bands) ────────────────
 454    # Lens mass model ellipticity
 455    e1, e2 = rng.normal(0, 0.15, size=2).clip(-0.5, 0.5)
 456
 457    # Lens light: INTERPOL (real elliptical stamp) or Sersic
 458    use_interpol_lens = lens_stamps is not None
 459    if use_interpol_lens:
 460        n_lens_stamps = len(lens_stamps[BANDS[0]])
 461        lens_stamp_idx = int(rng.integers(n_lens_stamps))
 462        lens_phi_G = float(rng.uniform(0, 2 * np.pi))
 463        lens_flip = bool(rng.random() > 0.5)
 464    else:
 465        R_sersic_lens = float(truncnorm.rvs(0, 3, loc=0.3, scale=0.3,
 466                              random_state=int(rng.integers(int(1e9)))))
 467        n_sersic_lens = float(rng.uniform(2, 6))
 468
 469    # Source galaxy: INTERPOL (real galaxy stamp) or Sersic
 470    use_interpol = source_stamps is not None
 471    if use_interpol:
 472        n_stamps = len(source_stamps[BANDS[0]])
 473        src_stamp_idx = int(rng.integers(n_stamps))
 474        src_phi_G = float(rng.uniform(0, 2 * np.pi))
 475        src_flip = bool(rng.random() > 0.5)
 476    else:
 477        R_sersic_src = float(truncnorm.rvs(0, 3, loc=0.15, scale=0.15,
 478                             random_state=int(rng.integers(int(1e9)))))
 479        n_sersic_src = float(rng.uniform(1, 4))
 480        e1s, e2s = rng.normal(0, 0.2, size=2).clip(-0.6, 0.6)
 481
 482    if lensed and theta_E > 0:
 483        src_offset = float(rng.uniform(0.0, 0.8 * theta_E))
 484        src_angle = float(rng.uniform(0, 2 * np.pi))
 485        center_x = src_offset * np.cos(src_angle)
 486        center_y = src_offset * np.sin(src_angle)
 487    else:
 488        center_x, center_y = rng.normal(0, 0.25, size=2)
 489
 490    gamma_ext = float(rng.uniform(0.0, 0.08))
 491    psi_ext = float(rng.uniform(0, np.pi))
 492    gamma1 = gamma_ext * np.cos(2 * psi_ext)
 493    gamma2 = gamma_ext * np.sin(2 * psi_ext)
 494
 495    # ── Source calibration (done once in F115W, then scaled) ─────────
 496    scale_up = 10**float(rng.uniform(0, 2))
 497    src_flux_njy = float(truncnorm.rvs(0, 3, loc=50, scale=80,
 498                         random_state=int(rng.integers(int(1e9)))))
 499    calc_sum_src_f115w = sum_to_flux * src_flux_njy
 500    lStar = mStar / ML_ratio(max(z_lens, 0.01))
 501    calc_sum_lens_f115w = sum_to_flux * lStar
 502
 503    # SED color ratios — randomize UV slope for source diversity
 504    uv_slope = float(np.clip(rng.normal(-0.1, 0.7), -1.5, 1.5))
 505    lens_colors = elliptical_color_ratios(z_lens)
 506    src_colors = starforming_color_ratios(z_source, uv_slope=uv_slope)
 507
 508    # ── Render in each band ──────────────────────────────────────────
 509    band_results = {}
 510
 511    for band in BANDS:
 512        cfg = BAND_CONFIG[band]
 513        pixels = cfg['pixels']
 514        pixel_scale = cfg['pixel_scale']
 515
 516        kwargs_data = make_kwargs_data(band)
 517        data_class = ImageData(**kwargs_data)
 518        # Use delta PSF when INTERPOL stamps (pre-convolved), real PSF for Sersic
 519        if use_interpol and use_interpol_lens:
 520            psf_class = make_delta_psf()
 521        else:
 522            psf_class = make_psf_obj(band)
 523
 524        # Source model: INTERPOL (real galaxy) or SERSIC_ELLIPSE (fallback)
 525        if use_interpol:
 526            stamp = source_stamps[band][src_stamp_idx].copy()
 527            if src_flip:
 528                stamp = np.ascontiguousarray(np.fliplr(stamp))
 529            source_model = LightModel(['INTERPOL'])
 530            kwargs_source = [{
 531                'image': stamp.astype(np.float64),
 532                'amp': 1,
 533                'center_x': float(center_x),
 534                'center_y': float(center_y),
 535                'phi_G': src_phi_G,
 536                'scale': SOURCE_STAMP_SCALE,
 537            }]
 538        else:
 539            source_model = LightModel(['SERSIC_ELLIPSE'])
 540            kwargs_source = [{
 541                'amp': 1, 'R_sersic': R_sersic_src, 'n_sersic': n_sersic_src,
 542                'e1': float(e1s), 'e2': float(e2s),
 543                'center_x': float(center_x), 'center_y': float(center_y)}]
 544
 545        # Lens light: INTERPOL (real elliptical stamp) or SERSIC_ELLIPSE
 546        if use_interpol_lens:
 547            lens_stamp = lens_stamps[band][lens_stamp_idx].copy()
 548            if lens_flip:
 549                lens_stamp = np.ascontiguousarray(np.fliplr(lens_stamp))
 550            lens_light_model = LightModel(['INTERPOL'])
 551            kwargs_lens_light = [{
 552                'image': lens_stamp.astype(np.float64),
 553                'amp': 1,
 554                'center_x': 0., 'center_y': 0.,
 555                'phi_G': lens_phi_G,
 556                'scale': LENS_STAMP_SCALE,
 557            }]
 558        else:
 559            lens_light_model = LightModel(['SERSIC_ELLIPSE'])
 560            kwargs_lens_light = [{
 561                'amp': 1, 'R_sersic': R_sersic_lens, 'n_sersic': n_sersic_lens,
 562                'e1': float(e1), 'e2': float(e2), 'center_x': 0., 'center_y': 0.}]
 563
 564        lens_model = LensModel(['SIE', 'SHEAR'], z_lens=z_lens, z_source=z_source)
 565
 566        image_model = ImageModel(
 567            data_class=data_class, psf_class=psf_class,
 568            lens_model_class=lens_model,
 569            source_model_class=source_model,
 570            lens_light_model_class=lens_light_model,
 571            kwargs_numerics=KWARGS_NUMERICS)
 572
 573        kwargs_lens = [
 574            {'theta_E': theta_E, 'e1': float(e1), 'e2': float(e2),
 575             'center_x': 0., 'center_y': 0.},
 576            {'gamma1': gamma1, 'gamma2': gamma2}
 577        ]
 578
 579        # Scale fluxes by SED color ratio relative to F115W
 580        calc_sum_src = calc_sum_src_f115w * src_colors[band]
 581        calc_sum_lens = calc_sum_lens_f115w * lens_colors[band]
 582
 583        # Calibrate source amplitude
 584        img_src = image_model.image(kwargs_lens, kwargs_source,
 585                                    kwargs_lens_light=kwargs_lens_light,
 586                                    source_add=True, lens_light_add=False)
 587        s_src = np.sum(img_src)
 588        if s_src <= 0:
 589            return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 590        kwargs_source[0]['amp'] = (calc_sum_src / s_src) * scale_up
 591
 592        if not lensed:
 593            kwargs_source[0]['amp'] = 0.0
 594
 595        # Calibrate lens light amplitude
 596        img_lens = image_model.image(kwargs_lens, kwargs_source,
 597                                     kwargs_lens_light=kwargs_lens_light,
 598                                     source_add=False, lens_light_add=True)
 599        s_lens = np.sum(img_lens)
 600        if s_lens <= 0:
 601            return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 602        kwargs_lens_light[0]['amp'] = calc_sum_lens / s_lens
 603
 604        # Set arc/lens flux ratio from a realistic distribution
 605        # Real systems (SLACS/COWLS): arc/lens ~ 0.05–0.5 in the arc band
 606        if lensed and calc_sum_lens > 0:
 607            target_ratio = 10**float(rng.uniform(np.log10(ARC_LENS_MIN_RATIO),
 608                                                  np.log10(0.5)))
 609            # Current arc flux after source calibration
 610            current_arc = np.sum(image_model.image(
 611                kwargs_lens, kwargs_source,
 612                kwargs_lens_light=kwargs_lens_light,
 613                source_add=True, lens_light_add=False))
 614            current_lens = np.sum(image_model.image(
 615                kwargs_lens, kwargs_source,
 616                kwargs_lens_light=kwargs_lens_light,
 617                source_add=False, lens_light_add=True))
 618            if current_arc > 0 and current_lens > 0:
 619                current_ratio = current_arc / current_lens
 620                kwargs_source[0]['amp'] *= (target_ratio / current_ratio)
 621
 622        # Final renders
 623        image = image_model.image(kwargs_lens, kwargs_source,
 624                                  kwargs_lens_light=kwargs_lens_light,
 625                                  source_add=True, lens_light_add=True)
 626        image_source = image_model.image(kwargs_lens, kwargs_source,
 627                                         kwargs_lens_light=kwargs_lens_light,
 628                                         source_add=True, lens_light_add=False)
 629
 630        band_results[band] = {
 631            'image': image.astype(np.float32),
 632            'image_source': image_source.astype(np.float32),
 633        }
 634
 635    return band_results, theta_E, z_lens, z_source, mass, mStar, uv_slope

 640def _simulate_worker(args):
 641    """Worker function for parallel simulation."""
 642    idx, lensed, seed, noise_seed = args
 643    result = simulate_one_multiband(lensed=lensed, seed=seed)
 644    band_results, theta_E, z_lens, z_source, mass, mStar, uv_slope = result
 645
 646    rng_noise = np.random.default_rng(noise_seed)
 647
 648    out = {'idx': idx, 'label': 1.0 if lensed else 0.0,
 649           'theta_E': theta_E, 'z_lens': z_lens, 'z_source': z_source, 'mass': mass,
 650           'images': {}, 'sources': {}, 'clean': {}}
 651
 652    # Same background index for all bands (spatially matched patches)
 653    bg_idx = int(rng_noise.integers(len(backgrounds[BANDS[0]])))
 654
 655    for band in BANDS:
 656        img = band_results[band]['image']
 657        img_noisy = add_poisson_noise(img, band, rng=rng_noise)
 658        bg = backgrounds[band][bg_idx]
 659        out['images'][band] = (img_noisy + bg).astype(np.float32)
 660        out['sources'][band] = band_results[band]['image_source'].astype(np.float32)
 661        out['clean'][band] = img_noisy.astype(np.float32)
 662
 663    return out

 822    def make_rgb(r, g, b, stretch=0.10, Q=12, sat_boost=1.8,
 823                 percentile_bg=5.0, smooth_sigma=1.5, lum_floor=0.06):
 824        """Lupton et al. (2004) RGB composite with COWLS-style cleanup.
 825
 826        stretch: linear region size (lower = more contrast in faint features)
 827        Q: asinh softening (higher = more dynamic range compression)
 828        sat_boost: color saturation multiplier (>1 = more vivid)
 829        percentile_bg: percentile to subtract as background (black level)
 830        smooth_sigma: Gaussian smooth for noise reduction (display only)
 831        lum_floor: luminance threshold below which pixels fade to black
 832        """
 833        from astropy.visualization import make_lupton_rgb
 834        r = np.nan_to_num(r, nan=0.0).astype(np.float64)
 835        g = np.nan_to_num(g, nan=0.0).astype(np.float64)
 836        b = np.nan_to_num(b, nan=0.0).astype(np.float64)
 837        # Gaussian smooth for noise reduction (matches COWLS ~2x display downsample)
 838        if smooth_sigma > 0:
 839            r = gaussian_filter(r, smooth_sigma)
 840            g = gaussian_filter(g, smooth_sigma)
 841            b = gaussian_filter(b, smooth_sigma)
 842        # Subtract background so sky is black
 843        for ch in [r, g, b]:
 844            ch -= np.percentile(ch, percentile_bg)
 845            ch[ch < 0] = 0
 846        rgb = make_lupton_rgb(r, g, b, stretch=stretch, Q=Q, minimum=0)
 847        rgb_f = rgb.astype(np.float32) / 255.0
 848        # Boost color saturation
 849        if sat_boost != 1.0:
 850            lum = 0.2989 * rgb_f[:,:,0] + 0.5870 * rgb_f[:,:,1] + 0.1140 * rgb_f[:,:,2]
 851            for ch in range(3):
 852                rgb_f[:,:,ch] = lum + sat_boost * (rgb_f[:,:,ch] - lum)
 853            rgb_f = np.clip(rgb_f, 0, 1)
 854        # Luminance floor: push noise-dominated pixels to black
 855        if lum_floor > 0:
 856            lum = np.max(rgb_f, axis=2)
 857            gate = np.clip((lum - lum_floor) / lum_floor, 0, 1)
 858            for ch in range(3):
 859                rgb_f[:,:,ch] *= gate
 860        return (np.clip(rgb_f, 0, 1) * 255).astype(np.uint8)

 879    # RGB channel mapping: R=F444W, G=F277W, B=(F115W+F150W)/2
 880    # Standard COSMOS-Web convention (Casey, Franco et al.)
 881    def _rgb_channels(img_dict, norm_dict):
 882        """Return (r, g, b) from 4-band image dict using COSMOS-Web convention."""
 883        r = img_dict['F444W'] / norm_dict['F444W']

 245def elliptical_color_ratios(z_lens):

 249    At z > 1, the 4000A break moves through F150W and into F277W,

 258def starforming_color_ratios(z_source, uv_slope=0.5):
 259    """NIRCam flux ratios for a star-forming galaxy at z_source.
 260
 261    v3: Lyman-break aware + UV slope diversity.
 262
 263    uv_slope controls the f_nu spectral index: ratio = (1.15/lambda)^uv_slope
 264      uv_slope > 0: blue (dust-free young starburst)
 265      uv_slope ~ 0: flat in f_nu
 266      uv_slope < 0: red (dusty star-forming, or older stellar population)
 267    """
 268    # Lyman break wavelength at this redshift (in microns)
 269    ly_break_um = 0.1216 * (1 + z_source)
 270
 271    # Band effective wavelengths (microns)
 272    band_waves = {&"cm">#x27;F115W&#x27;: 1.15, &#x27;F150W&#x27;: 1.50, &#x27;F277W&#x27;: 2.77, &#x27;F444W&#x27;: 4.44}
 273
 274    ratios = {}
 275    for band, lam_eff in band_waves.items():
 276        if lam_eff < ly_break_um:
 277            # Below Lyman break — strong IGM absorption
 278            suppression = max(0.0, (lam_eff / ly_break_um) ** 3)
 279            ratio = suppression * 0.05
 280        else:
 281            # Above Lyman break — UV continuum with slope diversity
 282            ratio = (1.15 / lam_eff) ** uv_slope
 283        ratios[band] = max(ratio, 0.01)
 284
 285    # Normalize to F115W if it's above the break
 286    f115w_val = ratios[&"cm">#x27;F115W&#x27;]
 287    if f115w_val > 0.01:
 288        for band in ratios:
 289            ratios[band] /= f115w_val
 290    else:
 291        max_val = max(ratios.values())
 292        if max_val > 0.01:
 293            for band in ratios:
 294                ratios[band] /= max_val
 295
 296    return ratios

 301def add_poisson_noise(image_sim, band, rng=None):
 302    """Add Poisson shot noise to noiseless sim image."""
 303    if rng is None:
 304        rng = np.random.default_rng()
 305    s2e = BAND_CONFIG[band][&"cm">#x27;sim_to_elec&#x27;]
 306    electrons = np.nan_to_num(image_sim * s2e, nan=0.0, posinf=0.0, neginf=0.0)
 307    electrons = np.clip(electrons, 0, None)
 308    # For very large lambda, use Gaussian approximation (Poisson→Normal)
 309    large = electrons > 1e8
 310    if large.any():
 311        noisy = np.empty_like(electrons)
 312        noisy[~large] = rng.poisson(electrons[~large]).astype(np.float64)
 313        noisy[large] = rng.normal(electrons[large], np.sqrt(electrons[large]))
 314        noisy = np.clip(noisy, 0, None)
 315    else:
 316        noisy = rng.poisson(electrons).astype(np.float64)
 317    return (noisy / s2e).astype(np.float32)

 380#   - Stellar masses: mostly log M* < 11 (cf. SLACS > 11)
 381#   - Lens magnitudes: F444W 16-22 AB (cf. SLACS 15-17)
 382
 383# v2: TruncNorm(loc=0.3, scale=0.15, [0.05, 0.90])  — SLACS
 384# v3: TruncNorm(loc=0.7, scale=0.4,  [0.05, 2.5])   — COWLS
 385ZLENS_LOC, ZLENS_SCALE = 0.7, 0.4
 386ZLENS_LO, ZLENS_HI = 0.05, 2.5
 387
 388# v2: TruncNorm(loc=1.5, scale=0.8, [0.6, 3.0])     — SLACS
 389# v3: TruncNorm(loc=2.5, scale=1.5, [0.5, 7.0])     — COWLS (sources to z~9)
 390ZSRC_LOC, ZSRC_SCALE = 2.5, 1.5
 391ZSRC_LO, ZSRC_HI = 0.5, 7.0
 392
 393# v2: TruncNorm(loc=215, scale=50, [100, 400]) km/s  — SLACS
 394# v3: TruncNorm(loc=180, scale=50, [80, 350]) km/s   — COWLS (lower-mass, smaller theta_E)
 395SIGMA_LOC, SIGMA_SCALE = 180, 50
 396SIGMA_LO, SIGMA_HI = 80, 350
 397
 398# v2: theta_E must be in [0.5, 1.5]"                  — SLACS
 399# v3: theta_E must be in [0.2, 1.5]"                  — COWLS (most below 1.0")
 400THETA_E_LO, THETA_E_HI = 0.2, 1.5
 401
 402# v2: log_mass ~ U(11.5, 13.0)                        — SLACS
 403# v3: log_mass ~ U(11.0, 13.0)                        — COWLS (lower-mass lenses)
 404LOGMASS_LO, LOGMASS_HI = 11.0, 13.0

 407# ── Multi-band simulation ───────────────────────────────────────────────
 408
 409def simulate_one_multiband(lensed=True, seed=None):
 410    """Simulate one lens system in all 4 bands.
 411
 412    Returns dict with keys per band, each containing (image, image_source).
 413    Also returns shared params: theta_E, z_lens, z_source, mass, mStar.
 414    """
 415    rng = np.random.default_rng(seed)
 416
 417    # ── COWLS-calibrated redshifts ────────────────────────────────────
 418    z_lens = float(truncnorm.rvs(
 419        a=(ZLENS_LO - ZLENS_LOC) / ZLENS_SCALE,
 420        b=(ZLENS_HI - ZLENS_LOC) / ZLENS_SCALE,
 421        loc=ZLENS_LOC, scale=ZLENS_SCALE,
 422        random_state=int(rng.integers(int(1e9)))))
 423
 424    z_src_min = max(ZSRC_LO, z_lens + 0.1)
 425    for _ in range(100):
 426        z_source = float(truncnorm.rvs(
 427            a=(ZSRC_LO - ZSRC_LOC) / ZSRC_SCALE,
 428            b=(ZSRC_HI - ZSRC_LOC) / ZSRC_SCALE,
 429            loc=ZSRC_LOC, scale=ZSRC_SCALE,
 430            random_state=int(rng.integers(int(1e9)))))
 431        if z_source > z_lens + 0.1:
 432            break
 433    z_source = max(z_source, z_src_min)
 434
 435    # ── Velocity dispersion -> Einstein radius ───────────────────────
 436    sigma_v = float(truncnorm.rvs(
 437        a=(SIGMA_LO - SIGMA_LOC) / SIGMA_SCALE,
 438        b=(SIGMA_HI - SIGMA_LOC) / SIGMA_SCALE,
 439        loc=SIGMA_LOC, scale=SIGMA_SCALE,
 440        random_state=int(rng.integers(int(1e9)))))
 441
 442    lens_cosmo = LensCosmo(z_lens, z_source)
 443    theta_E = lens_cosmo.sis_sigma_v2theta_E(sigma_v) if lensed else 0.0
 444
 445    if lensed and not (THETA_E_LO <= theta_E <= THETA_E_HI):
 446        return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 447
 448    # ── Halo mass (galaxy-scale) ─────────────────────────────────────
 449    log_mass = float(rng.uniform(LOGMASS_LO, LOGMASS_HI))
 450    mass = 10**log_mass
 451    mStar = stellar_mass(mass, z_lens)
 452
 453    # ── Galaxy shape parameters (shared across bands) ────────────────
 454    # Lens mass model ellipticity
 455    e1, e2 = rng.normal(0, 0.15, size=2).clip(-0.5, 0.5)
 456
 457    # Lens light: INTERPOL (real elliptical stamp) or Sersic
 458    use_interpol_lens = lens_stamps is not None
 459    if use_interpol_lens:
 460        n_lens_stamps = len(lens_stamps[BANDS[0]])
 461        lens_stamp_idx = int(rng.integers(n_lens_stamps))
 462        lens_phi_G = float(rng.uniform(0, 2 * np.pi))
 463        lens_flip = bool(rng.random() > 0.5)
 464    else:
 465        R_sersic_lens = float(truncnorm.rvs(0, 3, loc=0.3, scale=0.3,
 466                              random_state=int(rng.integers(int(1e9)))))
 467        n_sersic_lens = float(rng.uniform(2, 6))
 468
 469    # Source galaxy: INTERPOL (real galaxy stamp) or Sersic
 470    use_interpol = source_stamps is not None
 471    if use_interpol:
 472        n_stamps = len(source_stamps[BANDS[0]])
 473        src_stamp_idx = int(rng.integers(n_stamps))
 474        src_phi_G = float(rng.uniform(0, 2 * np.pi))
 475        src_flip = bool(rng.random() > 0.5)
 476    else:
 477        R_sersic_src = float(truncnorm.rvs(0, 3, loc=0.15, scale=0.15,
 478                             random_state=int(rng.integers(int(1e9)))))
 479        n_sersic_src = float(rng.uniform(1, 4))
 480        e1s, e2s = rng.normal(0, 0.2, size=2).clip(-0.6, 0.6)
 481
 482    if lensed and theta_E > 0:
 483        src_offset = float(rng.uniform(0.0, 0.8 * theta_E))
 484        src_angle = float(rng.uniform(0, 2 * np.pi))
 485        center_x = src_offset * np.cos(src_angle)
 486        center_y = src_offset * np.sin(src_angle)
 487    else:
 488        center_x, center_y = rng.normal(0, 0.25, size=2)
 489
 490    gamma_ext = float(rng.uniform(0.0, 0.08))
 491    psi_ext = float(rng.uniform(0, np.pi))
 492    gamma1 = gamma_ext * np.cos(2 * psi_ext)
 493    gamma2 = gamma_ext * np.sin(2 * psi_ext)
 494
 495    # ── Source calibration (done once in F115W, then scaled) ─────────
 496    scale_up = 10**float(rng.uniform(0, 2))
 497    src_flux_njy = float(truncnorm.rvs(0, 3, loc=50, scale=80,
 498                         random_state=int(rng.integers(int(1e9)))))
 499    calc_sum_src_f115w = sum_to_flux * src_flux_njy
 500    lStar = mStar / ML_ratio(max(z_lens, 0.01))
 501    calc_sum_lens_f115w = sum_to_flux * lStar
 502
 503    # SED color ratios — randomize UV slope for source diversity
 504    uv_slope = float(np.clip(rng.normal(-0.1, 0.7), -1.5, 1.5))
 505    lens_colors = elliptical_color_ratios(z_lens)
 506    src_colors = starforming_color_ratios(z_source, uv_slope=uv_slope)
 507
 508    # ── Render in each band ──────────────────────────────────────────
 509    band_results = {}
 510
 511    for band in BANDS:
 512        cfg = BAND_CONFIG[band]
 513        pixels = cfg[&"cm">#x27;pixels&#x27;]
 514        pixel_scale = cfg[&"cm">#x27;pixel_scale&#x27;]
 515
 516        kwargs_data = make_kwargs_data(band)
 517        data_class = ImageData(**kwargs_data)
 518        # Use delta PSF when INTERPOL stamps (pre-convolved), real PSF for Sersic
 519        if use_interpol and use_interpol_lens:
 520            psf_class = make_delta_psf()
 521        else:
 522            psf_class = make_psf_obj(band)
 523
 524        # Source model: INTERPOL (real galaxy) or SERSIC_ELLIPSE (fallback)
 525        if use_interpol:
 526            stamp = source_stamps[band][src_stamp_idx].copy()
 527            if src_flip:
 528                stamp = np.ascontiguousarray(np.fliplr(stamp))
 529            source_model = LightModel([&"cm">#x27;INTERPOL&#x27;])
 530            kwargs_source = [{
 531                &"cm">#x27;image&#x27;: stamp.astype(np.float64),
 532                &"cm">#x27;amp&#x27;: 1,
 533                &"cm">#x27;center_x&#x27;: float(center_x),
 534                &"cm">#x27;center_y&#x27;: float(center_y),
 535                &"cm">#x27;phi_G&#x27;: src_phi_G,
 536                &"cm">#x27;scale&#x27;: SOURCE_STAMP_SCALE,
 537            }]
 538        else:
 539            source_model = LightModel([&"cm">#x27;SERSIC_ELLIPSE&#x27;])
 540            kwargs_source = [{
 541                &"cm">#x27;amp&#x27;: 1, &#x27;R_sersic&#x27;: R_sersic_src, &#x27;n_sersic&#x27;: n_sersic_src,
 542                &"cm">#x27;e1&#x27;: float(e1s), &#x27;e2&#x27;: float(e2s),
 543                &"cm">#x27;center_x&#x27;: float(center_x), &#x27;center_y&#x27;: float(center_y)}]
 544
 545        # Lens light: INTERPOL (real elliptical stamp) or SERSIC_ELLIPSE
 546        if use_interpol_lens:
 547            lens_stamp = lens_stamps[band][lens_stamp_idx].copy()
 548            if lens_flip:
 549                lens_stamp = np.ascontiguousarray(np.fliplr(lens_stamp))
 550            lens_light_model = LightModel([&"cm">#x27;INTERPOL&#x27;])
 551            kwargs_lens_light = [{
 552                &"cm">#x27;image&#x27;: lens_stamp.astype(np.float64),
 553                &"cm">#x27;amp&#x27;: 1,
 554                &"cm">#x27;center_x&#x27;: 0., &#x27;center_y&#x27;: 0.,
 555                &"cm">#x27;phi_G&#x27;: lens_phi_G,
 556                &"cm">#x27;scale&#x27;: LENS_STAMP_SCALE,
 557            }]
 558        else:
 559            lens_light_model = LightModel([&"cm">#x27;SERSIC_ELLIPSE&#x27;])
 560            kwargs_lens_light = [{
 561                &"cm">#x27;amp&#x27;: 1, &#x27;R_sersic&#x27;: R_sersic_lens, &#x27;n_sersic&#x27;: n_sersic_lens,
 562                &"cm">#x27;e1&#x27;: float(e1), &#x27;e2&#x27;: float(e2), &#x27;center_x&#x27;: 0., &#x27;center_y&#x27;: 0.}]
 563
 564        lens_model = LensModel([&"cm">#x27;SIE&#x27;, &#x27;SHEAR&#x27;], z_lens=z_lens, z_source=z_source)
 565
 566        image_model = ImageModel(
 567            data_class=data_class, psf_class=psf_class,
 568            lens_model_class=lens_model,
 569            source_model_class=source_model,
 570            lens_light_model_class=lens_light_model,
 571            kwargs_numerics=KWARGS_NUMERICS)
 572
 573        kwargs_lens = [
 574            {&"cm">#x27;theta_E&#x27;: theta_E, &#x27;e1&#x27;: float(e1), &#x27;e2&#x27;: float(e2),
 575             &"cm">#x27;center_x&#x27;: 0., &#x27;center_y&#x27;: 0.},
 576            {&"cm">#x27;gamma1&#x27;: gamma1, &#x27;gamma2&#x27;: gamma2}
 577        ]
 578
 579        # Scale fluxes by SED color ratio relative to F115W
 580        calc_sum_src = calc_sum_src_f115w * src_colors[band]
 581        calc_sum_lens = calc_sum_lens_f115w * lens_colors[band]
 582
 583        # Calibrate source amplitude
 584        img_src = image_model.image(kwargs_lens, kwargs_source,
 585                                    kwargs_lens_light=kwargs_lens_light,
 586                                    source_add=True, lens_light_add=False)
 587        s_src = np.sum(img_src)
 588        if s_src <= 0:
 589            return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 590        kwargs_source[0][&"cm">#x27;amp&#x27;] = (calc_sum_src / s_src) * scale_up
 591
 592        if not lensed:
 593            kwargs_source[0][&"cm">#x27;amp&#x27;] = 0.0
 594
 595        # Calibrate lens light amplitude
 596        img_lens = image_model.image(kwargs_lens, kwargs_source,
 597                                     kwargs_lens_light=kwargs_lens_light,
 598                                     source_add=False, lens_light_add=True)
 599        s_lens = np.sum(img_lens)
 600        if s_lens <= 0:
 601            return simulate_one_multiband(lensed=lensed, seed=int(rng.integers(int(1e9))))
 602        kwargs_lens_light[0][&"cm">#x27;amp&#x27;] = calc_sum_lens / s_lens
 603
 604        # Set arc/lens flux ratio from a realistic distribution
 605        # Real systems (SLACS/COWLS): arc/lens ~ 0.05–0.5 in the arc band
 606        if lensed and calc_sum_lens > 0:
 607            target_ratio = 10**float(rng.uniform(np.log10(ARC_LENS_MIN_RATIO),
 608                                                  np.log10(0.5)))
 609            # Current arc flux after source calibration
 610            current_arc = np.sum(image_model.image(
 611                kwargs_lens, kwargs_source,
 612                kwargs_lens_light=kwargs_lens_light,
 613                source_add=True, lens_light_add=False))
 614            current_lens = np.sum(image_model.image(
 615                kwargs_lens, kwargs_source,
 616                kwargs_lens_light=kwargs_lens_light,
 617                source_add=False, lens_light_add=True))
 618            if current_arc > 0 and current_lens > 0:
 619                current_ratio = current_arc / current_lens
 620                kwargs_source[0][&"cm">#x27;amp&#x27;] *= (target_ratio / current_ratio)
 621
 622        # Final renders
 623        image = image_model.image(kwargs_lens, kwargs_source,
 624                                  kwargs_lens_light=kwargs_lens_light,
 625                                  source_add=True, lens_light_add=True)
 626        image_source = image_model.image(kwargs_lens, kwargs_source,
 627                                         kwargs_lens_light=kwargs_lens_light,
 628                                         source_add=True, lens_light_add=False)
 629
 630        band_results[band] = {
 631            &"cm">#x27;image&#x27;: image.astype(np.float32),
 632            &"cm">#x27;image_source&#x27;: image_source.astype(np.float32),
 633        }
 634
 635    return band_results, theta_E, z_lens, z_source, mass, mStar, uv_slope

 638# ── Parallel worker ───────────────────────────────────────────────────

 640def _simulate_worker(args):
 641    """Worker function for parallel simulation."""
 642    idx, lensed, seed, noise_seed = args
 643    result = simulate_one_multiband(lensed=lensed, seed=seed)
 644    band_results, theta_E, z_lens, z_source, mass, mStar, uv_slope = result
 645
 646    rng_noise = np.random.default_rng(noise_seed)
 647
 648    out = {&"cm">#x27;idx&#x27;: idx, &#x27;label&#x27;: 1.0 if lensed else 0.0,
 649           &"cm">#x27;theta_E&#x27;: theta_E, &#x27;z_lens&#x27;: z_lens, &#x27;z_source&#x27;: z_source, &#x27;mass&#x27;: mass,
 650           &"cm">#x27;images&#x27;: {}, &#x27;sources&#x27;: {}, &#x27;clean&#x27;: {}}
 651
 652    # Same background index for all bands (spatially matched patches)
 653    bg_idx = int(rng_noise.integers(len(backgrounds[BANDS[0]])))
 654
 655    for band in BANDS:
 656        img = band_results[band][&"cm">#x27;image&#x27;]
 657        img_noisy = add_poisson_noise(img, band, rng=rng_noise)
 658        bg = backgrounds[band][bg_idx]
 659        out[&"cm">#x27;images&#x27;][band] = (img_noisy + bg).astype(np.float32)
 660        out[&"cm">#x27;sources&#x27;][band] = band_results[band][&#x27;image_source&#x27;].astype(np.float32)
 661        out[&"cm">#x27;clean&#x27;][band] = img_noisy.astype(np.float32)
 662
 663    return out

🌌

What does this program actually do?

Goal: Generate thousands of fake but realistic JWST images that look like real gravitational lenses — to train an ML classifier to find real ones in the COSMOS-Web survey data.

Strategy: Take real sky patches from COSMOS-Web as backgrounds, then mathematically ray-trace a source galaxy through a lens galaxy mass model (SIE + external shear) to produce lensed arcs. Add realistic PSF convolution, Poisson shot noise, and real background — making the result indistinguishable from a real JWST image.

Output: For each system: 4-band images (F115W, F150W, F277W, F444W), arc-only ground truth, and physical parameters (θ_E, z_lens, z_source, halo mass). Half of all generated images are non-lensed (label=0) for the classifier's negative class.

⚡
Strong Gravitational Lensing — 30-second primer

A massive foreground galaxy (the lens) bends light from a background galaxy (the source). When alignment is close, the source is stretched into arcs or rings. The Einstein radius θ_E (in arcseconds) is the characteristic angular scale — it depends on the lens mass and the ratio of angular diameter distances Dls/Ds. The code uses an SIE (Singular Isothermal Ellipsoid) mass model — the standard workhorse for galaxy-scale lensing. Einstein radius formula for SIE: θ_E = 4π(σ_v/c)² × Dls/Ds.

Pipeline overview

① prep_mosaic.py — Extract backgrounds & PSFs

Opens the COSMOS-Web FITS mosaics (~160 GB). Extracts 2000 spatially-matched sky background patches and empirical PSF kernels per band. Saves to prepped_mosaic/.

② prep_sources.py — Extract galaxy stamps

Detects real extended galaxies in the mosaic (15σ, concentration < 0.45 to reject stars). Extracts 500+ background-subtracted, normalized galaxy stamps per band for use as realistic source morphology.

③ simulate_v3.py — Generate lensing images (THIS FILE)

Sample physical parameters → ray-trace lensing with lenstronomy → scale fluxes per SED → add Poisson noise → add real background. Runs in parallel across all CPU cores.

④ train_cvae.py — Train ML model

💡 The unit conversion chain

Two critical conversion factors are pre-computed per band:

mjysr_to_sim — converts the real JWST mosaic pixel values (MJy/sr) into lenstronomy sim units. This is applied when loading backgrounds so they can be added directly to simulated images.

Chain: MJy/sr × pixar_sr [sr/pix] × 10¹⁵ [nJy/MJy] × sum_to_flux [sim/nJy] = sim units/pix

sim_to_elec — converts lenstronomy sim units back to detected electrons. Needed for Poisson noise: noise statistics are determined by photon counts, not flux units. Chain: sim → MJy/sr → DN/s → DN → electrons (× gain)

PHOTMJSR (from FITS header) = the JWST pipeline's photometric calibration constant, converting from instrument count-rate units to physical MJy/sr.

gain = 2.05 e⁻/ADU — NIRCam's typical detector conversion. Converts digital numbers (ADU counts) to actual photo-electrons.

💡 Two galaxy types, two SED models

Elliptical (lens galaxy) — old, passively evolved galaxy. Dominated by old red stars with a characteristic 4000 Å break (sharp flux drop below 4000 Å from stellar absorption). As z_lens increases, this break redshifts through the NIRCam bands, making the galaxy progressively redder toward F444W. The linear-in-z formulas are a simple empirical approximation of this effect.

Star-forming (source galaxy) — young, blue, actively star-forming galaxy. Two key spectral features:

  • UV continuum — power law in f_ν: flux ∝ λ^(-uv_slope). More positive uv_slope = bluer (more UV)
  • Lyman break at λ = 912 Å (the series limit of hydrogen ionization). At this wavelength, nearly all photons are absorbed by neutral hydrogen. Redshifted to observer wavelength: λ_obs = 912 Å × (1+z_source) ≈ 0.1216 µm × (1+z_source) (using Lyman-alpha as the break proxy). Flux below this is suppressed to ~5% (some transmitted through IGM windows). At z_source > 9 this pushes into F444W — the galaxy becomes a "dropout".

uv_slope ~ N(-0.1, 0.7) — a random UV spectral index giving each simulated source a different color, producing a realistic distribution of arc colors in the training set.

Poisson Shot Noise

Lines 299–317NoisePhysics
⚛️
Why Poisson noise?

Photons are discrete particles. If you expect λ photons to hit a pixel, the actual count follows a Poisson distribution with mean λ and variance λ. This shot noise (σ = √λ) is the fundamental quantum limit of any astronomical measurement — it cannot be removed by better electronics. Getting this right is essential so the ML model learns to cope with real noise, not unrealistically smooth images.

301def add_poisson_noise(image_sim, band, rng=None):
305    s2e = BAND_CONFIG[band]['sim_to_elec']
306    electrons = np.nan_to_num(image_sim * s2e, ...)
307    electrons = np.clip(electrons, 0, None)
   
309    large = electrons > 1e8
312    noisy[~large] = rng.poisson(electrons[~large])
313    noisy[large]  = rng.normal(electrons[large],
                          np.sqrt(electrons[large]))
       # Gaussian approx: Poisson(λ) → N(λ,√λ) for λ≫1
   
317    return (noisy / s2e).astype(np.float32)

💡 Step-by-step noise logic

Step 1 — Convert to electrons: electrons = image_sim × sim_to_elec. Poisson statistics apply to photon counts (electrons), not flux units. You can't draw Poisson noise on MJy/sr values — they must first become actual photon counts.

Step 2 — Clip to zero: Negative pixels (from background subtraction) would break Poisson sampling. Any negative electron count is set to zero.

Step 3 — Draw Poisson sample: For each pixel with λ electrons expected, draw the actual measured count from Poisson(λ). This adds the correct statistical scatter.

Step 4 — Gaussian approximation for large λ: When λ > 10⁸ (extremely bright), numpy.random.poisson can overflow or be very slow. Since Poisson(λ) ≈ Normal(λ, √λ) for large λ (central limit theorem), a Gaussian draw is substituted. The threshold 10⁸ is far above where the approximation breaks down (~100).

Step 5 — Convert back: Divide by sim_to_elec to return to sim units. The image now has physically correct shot noise.

💡 Truncated normal distribution & rejection sampling

truncnorm.rvs — draws from a Gaussian clipped at hard limits. The a and b parameters are the cutoff distances in units of the standard deviation: a = (low − mean) / σ, b = (high − mean) / σ. 💡 The two-pass amplitude calibration trick

lenstronomy's amp parameter scales the total flux of a light model. The trick is a two-step calibration:

  1. Render a test image with amp=1 to measure the current total pixel sum.
  2. Set amp = desired_flux / current_sum — this guarantees the next render has exactly the right total flux.

SED scaling: The reference flux is computed in F115W (calc_sum_src_f115w), then multiplied by the per-band SED color ratio for the current band. This ensures the 4-band flux ratios match the physically expected galaxy SED.

Arc/lens ratio: In real SLACS/COWLS systems, arcs are typically 10–50% as bright as the lens galaxy in the arc band. The code draws a random log-uniform target ratio in this range. This prevents the classifier from trivially identifying lenses by brightness alone — the arcs span the full range from barely visible to nearly as bright as the lens.

scale_up (line 496): An additional 1–100× random brightness boost applied before calibration. This covers a wide range of intrinsic source luminosities without fully modeling the luminosity function.

💡 Worker design and critical choices

Two separate seeds — seed (physics) and noise_seed (noise). This separation means you can regenerate the same lens system with a different noise realization, or study how much noise affects classification — without re-sampling all the physics parameters.

Same bg_idx for all bands — this is critical for physical realism. The background patches from prep_mosaic.py were extracted from the same sky coordinates in all 4 bands. out['clean'] — stored for only the first 5 lensed systems (for preview generation). Contains the noisy signal without the real background sky — useful for visually comparing "how bright is the arc vs the sky noise".

Label convention: label = 1.0 for lensed, 0.0 for non-lensed. The non-lensed images are generated with lensed=False, which sets kwargs_source[0]['amp'] = 0.0 — no source flux at all. The lens galaxy light and background are still present, making the negative class realistic.

💡 Memory mapping and parallel pool

Memory-mapped arrays (memmap) — for large datasets (e.g. N=10,000, 4 bands, 125×125, float32 ≈ 3.1 GB), storing everything in RAM isn't practical on all machines. np.lib.format.open_memmap creates a .npy file on disk and maps it into virtual memory. Each worker writes its result directly to the correct slice of the file — no RAM buffering required.

Fixed main seed (99) — pre-generating all seeds from a fixed root ensures the entire dataset is reproducible. If you run with --n 1000 twice, you get identical images. This is essential for scientific reproducibility and debugging.

mp.get_context('fork') — on Linux (including NERSC), "fork" copies the parent process's entire memory (loaded backgrounds, PSFs, stamps) to each worker instantly. Far faster than 'spawn' which would reload all data per worker. Note: 'fork' is not safe on macOS with some libraries — use 'spawn' there.

imap_unordered — streams results back as soon as each worker finishes (not waiting for the full chunk). Combined with memmap, results are committed to disk as they arrive.
