Bottom line

THE PROPOSAL  Train one small 4-band patch discriminator (spectral norm, hinge loss, ≤3M params, patch-score heatmaps) and one fixed readout suite (heatmaps, per-band ablations, metadata correlations), then run that identical machinery through seven experiments ("ideas") on Nate's ready-made datasets. The discriminator's explanation of how it separates sim from real is the deliverable.

Two things flipped since the last rewrite:

  • The data famine is over. We planned around a 92-image cap; there are now 6,961 systems (2,500 + 3,650 lensed, plus 811 non-lensed) sitting on CFS — roughly 75× more than the cap, with far richer metadata. We no longer generate sims; we consume them.
  • The binding constraint moved. The scene library switched from COSMOS-Web to JADES (GOODS-N/S), while the only sizable real-lens sample (COWLS, 440 systems) is COSMOS-Web. Handling that survey gap — not network architecture, not dataset size — is now the hard part. Idea 2 measures it; Idea 1 works around it.

Per system (all float32 (N, 630, 630), 4 bands, memory-map these)

  • images_<band>.npy — final composite (real scene + arcs + noise); images_<band>_zoom.npy in v13.
  • arcs_<band>.npy — noiseless arc-only layer. Doubles as a perfect arc mask and lets us rescale arc flux or re-draw noise at training time (the README explicitly invites this — see Idea 5).
  • galaxies_<band>.npy — the untouched real JADES scene. images ≈ galaxies + arcs + noise, i.e. exact with/without pairs for every lensed sim (Idea 3).

Per-system metadata (the readout suite's fuel)

theta_Es, z_lens (JADES photo-z / DESI spec-z), z_source (VELA-native in v13), sigma_v consensus + per-band FJ predictions (sigma_v_F115W/150/277), per-band lens AB magnitudes (photom_*), einstein_mass_msun, lensed, completed_mask (all complete). One gap: no scene_idx array — scene identity must be reconstructed by grouping on the per-scene photometry values (works, since photometry is identical for all sims sharing a scene), or asked for (see asks).

The build (fixed across all ideas)

Input4 stacked bands; random 224×224 crops of the 630px frames (augmentation + working scale). Fixed per-band arcsinh normalization with sky stats from the real pile — never per-image min-max.
NetworkPatchGAN classifier: 4–5 stride-2 conv blocks (base 64), LeakyReLU(0.2), spectral norm everywhere, logit map output (heatmaps for free). ≤3M params — 440 real lenses is still the smallest pile in play.
Loss / protocolHinge loss. Split by scene (sims; ~6 sims share each scene — reconstruct scene IDs from photometry) and by system (reals); k-fold CV; PCA + logistic baseline first as the number to beat; class imbalance (6k sims vs 440 reals) handled by patch-level sampling and reweighting.
Readout(i) patch heatmaps, (ii) per-band ablations, (iii) D-score correlations against theta_Es, z_lens, z_source, sigma_v, photom_*, einstein_mass, scene ID — the metadata is rich enough that "D wins" converts directly into "the simulator is wrong here."

The ideas, in execution order

Idea 1 — Lensed sims vs. real COWLS lenses  PRIMARY

6,150 lensed sims vs. 4-band cutouts at the 440 cowls_catalogue.csv positions (COSMOS-Web mosaics, already on disk; one extraction script). Both piles contain a lens galaxy with arcs, so D must judge arc realism — the only thing the simulator actually fabricates. New since v13: the survey gap. Sims sit on JADES pixels, reals on COSMOS-Web pixels; depth/noise differences are a cheat code for D. Mitigations, in order of strength: (a) subtract Idea 2's measured survey signature from any claimed result; (b) normalize per survey and match local-background statistics; (c) prefer arc-annulus crops that minimize background exposure; (d) the clean fix — ask Nate for one run on COSMOS scenes (his own lens_scene_galaxies.csv lists 242 COSMOS positions).

Idea 2 — Real-vs-real controls  MANDATORY, RUN FIRST

Two null tests through the identical pipeline. (a) Pipeline honesty: the 811 non-lensed sims (= untouched real JADES cutouts, free from Nate's runs) vs. fresh JADES cutouts we extract — must score ~50% or our preprocessing is biased. (b) Survey signature: real JADES cutouts vs. real COSMOS-Web cutouts — deliberately not 50%; its accuracy quantifies the cheat available to Idea 1 and becomes the correction baseline. Cheap, decisive, zero training risk.

Idea 3 — Paired injection probe  ARTIFACT LOCALIZER

images vs. galaxies: 6,150 exact with/without-arc pairs, backgrounds pixel-identical. D wins trivially (arcs present vs. absent) — the value is the heatmaps: attention on arc boundaries or noise texture rather than arc bodies localizes injection artifacts (Poisson-only noise seam, PSF mismatch — the latter now acknowledged in Nate's own README). At 6k pairs this is a precision instrument, not the toy it would have been at 92 images.

Idea 4 — The zoom set as a second scale  CHEAP EXTENSION

v13's _zoom renders give every system a lens-centered close-up. Build matching zoom crops of the COWLS reals (catalogue einstein_radius sets the scale) and rerun Idea 1 at arc scale: concentrates capacity on simulated pixels, suppresses background memorization and survey-background cheats. Effectively the old "arc crops" option, except Nate already rendered half of it.

Idea 5 — Augmentation as experiment  TELL SURGERY

Because arcs_* is noiseless and separate, we can rebuild training images on the fly: galaxies + α·arcs + noise. Draw α from the COWLS-implied flux-ratio distribution and the fixed-0.25 tell (predicted tell #2) is surgically removed without touching the simulator; fresh Poisson draws also randomize the noise seam. Retrain D after each surgery: the accuracy drop measures how much of the gap that single tell explained — a clean, quantitative ranking Nate can act on. (His README suggests exactly this kind of α-scaling.)

Idea 6 — Version shootout: v8 → v9-4050 → v13  HEADLINE NUMBER

Identical training on each generation's output vs. the same real pile. If the consistency fixes (Faber–Jackson σ_v, unified scenes) closed real visual gaps, discriminability should fall monotonically across versions. One chart, instantly legible to the whole group.

Idea 7 — Zero-image checks  START TODAY

No training, no cutouts: compare theta_Es.npy against COWLS einstein_radius (v13 tops out at 1.69″; how much of the real distribution is missing?); the implied arc/lens flux ratios against COWLS lens+source magnitudes; sigma_v and einstein_mass against published lens-sample distributions. Catalog-vs-catalog statistics — publishable feedback this week.

Predicted tells — updated for the v13 code path

From v9_consistent/simulate_v9_consistent.py (line refs current). Three are now acknowledged in Nate's README — the discriminator's job is to rank their visibility and find what's missing from this list:

  1. Every lens has the same shape — e1, e2 = 0.05, 0.02 (L511), gamma1, gamma2 = 0.02, 0.01 (L540). Arcs are near-rings; quads/cusps/folds underrepresented. README-acknowledged.
  2. Fixed arc/lens flux ratio — target_ratio = 0.25 (L574). Real contrast spans decades. README-acknowledged; Idea 5 removes it at training time.
  3. Fixed source-offset fraction — src_offset = 0.3 * theta_E (L532), only the angle is random. One impact parameter ⇒ one arc-configuration family. New tell, found in this code read.
  4. Mass pinned to (0,0) (L545); the real galaxy is only near center — arcs can curve around a slightly wrong point.
  5. Noise seam at the arc footprint — injected arcs get uncorrelated Poisson noise; JADES mosaic noise is drizzle-correlated. Plus the PSF treatment mismatch (README-acknowledged).
  6. Identical arc morphology in all four bands — per-band-normalized VELA stamps × one analytic SED (L552–637).
  7. θ_E–brightness consistency — v9+ derives σ_v from scene photometry, so this v8 tell should be gone; the shootout (Idea 6) verifies.
